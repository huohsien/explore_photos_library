### Desired new REPORT-01 status model

Define a dedicated centralized enum or equivalent official definitions for REPORT-01 only:

```text
NO_PROBLEM
MISSING_ALBUM_IN_CURRENT
MISSING_BACKUP_MEMBERS
AMBIGUOUS_CURRENT_ALBUM_PATH
```

Definitions:

```text
NO_PROBLEM
- Current has one unambiguous corresponding AlbumPath.
- It contains every Backup member.
- Current extra members do not make it a problem.

MISSING_ALBUM_IN_CURRENT
- Backup has this AlbumPath.
- Current has no album container at that AlbumPath.

MISSING_BACKUP_MEMBERS
- Current has one unambiguous corresponding AlbumPath.
- At least one Backup member is absent from it.

AMBIGUOUS_CURRENT_ALBUM_PATH
- Current has 2+ different album container objects at the same canonical AlbumPath.
- Do not auto-repair until the duplicate-container ambiguity is resolved.
```

Current-only AlbumPaths may be optional diagnostics or an appendix statistic, but they are not part of the Backup restoration repair queue.

The redesigned report should be driven primarily by Backup AlbumPaths, not by the union of Backup and Current paths.

## Duplicate album container cleanup: side project

This work was done because duplicate Current album containers at one AlbumPath cause `AMBIGUOUS_CURRENT_ALBUM_PATH`, making structural repair unsafe.

Safe process:

```text
Probe exact AlbumPath
→ choose master
→ additive merge source memberships to master
→ verify expected unique union
→ delete source album containers only
→ rebuild and verify
```

Scripts intended as final versions:

```text

REPORT-07_AlbumPath_Additive-Merge_With-Manual-Master-Choice-step2.applescript
```
