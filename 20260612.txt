2026-06-12｜Photos Library Test 2 checkpoint

今天完成的主要事情：

1. 修正 syndicated asset routing

原本 explorephotoslibrary.py 會把 osxphotos 回報 syndicated=True 的 asset 直接放進 special_assets["SYNDICATED"]。

今天確認這個邏輯不對，因為 current_default 裡有很多 syndicated=True 的 asset 其實有正常 /originals/ local file，可以取得 file size，也能算 SHA。

已改成：

- syndicated=True 但有正常 /originals/ local original：
  放進 inventory["assets"]，參與正常 comparison。

- syndicated=True 但沒有正常 /originals/ local original：
  放進 special_assets["SYNDICATED_NO_NORMAL_ORIGINAL"]。

- normal asset 保留 syndicated property，之後可以看出這張是否來自分享 / syndication。

2. 修改 photo_library_asset_unique_id 的時間精度

原本 identity key 的 date component 精確到 centisecond。

今天改成只到秒：

(original_filename, MM-DD HH:MM:SS, file_size, adjustment_signature, sha256_if_needed)

理由：

- Photos / iCloud / syndicated / migration 可能讓 sub-second timestamp 漂移。
- 秒級時間搭配 file size、adjustment_signature、必要時 SHA，對這個 project 比較實用。
- 改成秒後曾暴露 backup 裡 IMG_8638.jpeg 有一組完全相同 SHA 的 duplicate，已手動確認並刪除一張。

3. Section 5 missing-current 從 14 降到 13

修正 syndicated routing + 秒級 date identity 後，IMG_8638.jpeg 從 ASSET_MISSING_FROM_CURRENT 清單消失。
